# Citizen Report App

A simple citizen reporting web application built using FastAPI.

## Features

- User authentication
- Report system
- Report status management
- Admin dashboard
- Announcement system
- Responsive UI
- Report inspection page

## Tech Stack

- FastAPI
- SQLAlchemy
- Jinja2
- SQLite
- HTML
- CSS

## Installation

Clone repository:

```bash
git clone <repo-url>
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run server:

```bash
uvicorn main:app --reload
```
or
```bash
python -m uvicorn main:app --reload
```
